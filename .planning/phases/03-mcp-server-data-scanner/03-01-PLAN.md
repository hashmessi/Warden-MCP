1. Import `createAdapterRegistry` from `./adapters/index.js`, `AuditLogger` from `./audit/logger.js`, `ScanResult` and `DataHit` from `./adapters/types.js`, and `randomUUID` from `crypto`.

2. Maintain an in-memory store: `const scanStore = new Map<string, ScanResult>();`

3. Export `async function scanSubject(identifier: string): Promise<ScanResult>`:
   - Create `scanId = randomUUID()` and `scannedAt = new Date().toISOString()`
   - Call `createAdapterRegistry()` to get adapters array
   - Fan out in parallel: `const results = await Promise.allSettled(adapters.map(a => a.findByIdentifier(identifier)))`
   - For each result: if `fulfilled`, collect `DataHit[]`; if `rejected`, log to stderr: `console.error('[scanner] Adapter error:', reason)` and continue
   - Collect successful hits, compute `totalRecords = hits.reduce((sum, h) => sum + h.rowCount, 0)`, collect `systemsScanned = [...new Set(hits.map(h => h.sourceSystem))]`
   - Build `ScanResult` object
   - Store in `scanStore.set(scanId, result)`
   - Log to audit: `await AuditLogger.appendLog({ action: "SCAN", actor: "mcp-client", subject: identifier, details: { scanId, totalRecords, systemsScanned } })`
   - Return the `ScanResult`

4. Export `function getScanResult(scanId: string): ScanResult | undefined` — returns `scanStore.get(scanId)`.

IMPORTANT: All debug logging MUST use `console.error()` only — never `console.log()` (stdout reserved for JSON-RPC).</action>

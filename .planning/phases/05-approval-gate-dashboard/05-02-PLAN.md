## What Was Built

The complete Next.js 15 ops console dashboard:

- **Design:** Dark glassmorphism (charcoal bg, glass cards, blur borders, vivid status accents)
- **Layout:** Split panel — compact requests list left, full detail panel right
- **Data:** React Query polling every 5 seconds via `/api/approvals`
- **Actions:** Approve/Deny with confirmation modal, single-use enforcement
- **API routes:** GET/POST `/api/approvals`, POST `/api/approvals/[token]/approve`, POST `/api/approvals/[token]/deny`
- **Demo data:** Store pre-seeded with 3 demo requests (pending/approved/denied)

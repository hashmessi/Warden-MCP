# Plan 08-01: Evaluation Core Types, Fault Injection Proxy, Invariants & Seeder

## Objective
Establish the foundational infrastructure for the Warden Evaluation Harness: strongly typed evaluation contracts, a transparent decorator/proxy for data adapter fault injection, an isolated dynamic subject seeder (`eval-<scenario>-<uuid>@warden.test`), and invariant verifier functions for pre-conditioned mutation, execution monotonicity, lossless reversibility, and audit integrity.

Create `src/eval/proxy.ts` implementing `FaultInjectionAdapter`:
- Wraps any `DataAdapter` (`systemName`, `findByIdentifier`, `deleteRecords`, `snapshotRecords`, `restoreRecords`, `getSchema`).
- Provides declarative configuration methods:
  - `failOn(method: 'deleteRecords' | 'restoreRecords' | 'snapshotRecords' | 'findByIdentifier', error?: Error): void`
  - `delay(method: string, delayMs: number): void`
  - `reset(): void`
- Intercepts calls: if a fault rule matches, injects the artificial delay or throws the configured error; otherwise delegates transparently to the underlying `targetAdapter`.
- Exports `createFaultProxy(adapter: DataAdapter): FaultInjectionAdapter`.
</action>

- `generateTestSubject(scenarioName: string): { email: string; userId: string }`
  Produces emails like `eval-${scenarioName}-${uuid.slice(0, 8)}@warden.test`.
- `seedTestSubject(subject: { email: string; userId: string }): Promise<void>`
  - Inserts 1 row into Postgres `users` (id, email, name, role)
  - Inserts 1 row into Postgres `user_profiles` (user_id, bio, phone, address)
  - Inserts 2 rows into Postgres `subscriptions` (user_id, plan, status, renews_at)
  - Inserts 3 rows into MongoDB `sessions` (userId, sessionToken, ipAddress, userAgent, expiresAt)
  - Inserts 2 entries into `paymentLedger` via `loadLedger()` or ledger append
- `cleanupTestSubject(subject: { email: string; userId: string }): Promise<void>`
  - Hard-deletes test rows from Postgres (`users`, `user_profiles`, `subscriptions`, `user_activity`, `scans`, `impact_reports`, `approvals`, `snapshots`, `execution_steps`)
  - Deletes test docs from MongoDB `sessions` and `activity_logs`
  - Cleans payment ledger entries
</action>

<action>
Create `src/eval/invariants.ts`:
- `assertAuthGate(approvalToken: string, mutationAllowed: boolean): Promise<boolean>`
  Verifies that mutation attempts with non-existent, pending, expired, or denied tokens are rejected.
- `assertIdempotency(token: string, executionCount: number): Promise<boolean>`
  Verifies that executing a token a second time throws/rejects and produces 0 additional mutations.
- `assertReversibility(subjectEmail: string, preRecordCount: number, postRollbackRecordCount: number): boolean`
  Verifies `postRollbackRecordCount === preRecordCount`.
- `assertTamperDetection(integrityResult: { valid: boolean; brokenAt?: number }): boolean`
  Verifies that any corrupted entry in `audit_log` is flagged with `valid === false`.
</action>

# Plan 08-03: Scorecard Terminal UI, Latency Analytics, Report Exporter & CLI Runner

## Objective
Build the terminal scorecard UI, calculate latency percentiles (p50/p95) and governance metrics, export persistent JSON/Markdown evaluation reports, and wire the `npm run eval` command into `package.json` with appropriate process exit codes.

---

## Tasks

<task>
<name>Build Latency Analytics and Terminal Scorecard Reporter</name>
<read_first>
  - src/eval/types.ts
</read_first>
<action>
Create `src/eval/reporter.ts`:
- `computeMetrics(results: EvalCaseResult[]): ScorecardMetrics`:
  - `totalCases`: results.length
  - `passed`: count where `status === 'PASSED'`
  - `failed`: count where `status === 'FAILED'`
  - `criticalFailures`: count where `status === 'CRITICAL_FAILURE'`
  - `rollbackSuccessRate`: percentage of rollback-enabled tests that restored data successfully
  - `unauthorizedExecutions`: count of tests violating `INV-01`
  - `duplicateExecutions`: count of tests violating `INV-02`
  - `auditTamperDetected`: boolean reflecting tamper scenario detection
  - `latencyP50Ms`: 50th percentile (median) duration across all cases
  - `latencyP95Ms`: 95th percentile duration across all cases
- `renderTerminalScorecard(metrics: ScorecardMetrics, results: EvalCaseResult[]): void`:
  - Renders a clean, high-impact ANSI box:
    ```
    ╔═══════════════════════════════════════════════════════════╗
    ║                     WARDEN EVALUATION                     ║
    ╠═══════════════════════════════════════════════════════════╣
    ║ Total Cases:         42                                   ║
    ║ Passed:              39                                   ║
    ║ Failed:              3                                    ║
    ║ Critical Failures:   0                                    ║
    ║ Rollback Success:    100.0%                               ║
    ║ Unauthorized Exec:   0                                    ║
    ║ Duplicate Exec:      0                                    ║
    ║ Audit Tamper:        DETECTED                             ║
    ║ Latency (p50 / p95): 42ms / 118ms                         ║
    ╚═══════════════════════════════════════════════════════════╝
    ```
  - Followed by a concise breakdown table of individual scenario statuses.
</action>
<acceptance_criteria>
- File `src/eval/reporter.ts` exists.
- Correctly calculates p50 and p95 latencies and rollback success percentages.
- `renderTerminalScorecard` outputs structured ANSI formatted table to console.
</acceptance_criteria>
</task>

<task>
<name>Build Report Exporter for CI/CD Persistence</name>
<read_first>
  - src/eval/types.ts
  - src/eval/reporter.ts
</read_first>
<action>
Create `src/eval/exporter.ts`:
- `exportReports(metrics: ScorecardMetrics, results: EvalCaseResult[]): Promise<{ jsonPath: string; mdPath: string }>`:
  - Ensures directory `.eval-results/` exists.
  - Writes `.eval-results/latest.json` with full raw results, case execution times, and computed metrics.
  - Writes `.eval-results/latest.md` with formatted markdown tables, suitable for CI summary comments or PR artifacts.
  - Also writes a timestamped archive copy `.eval-results/eval-${Date.now()}.json` for historical benchmarking.
</action>
<acceptance_criteria>
- File `src/eval/exporter.ts` exists.
- Exports both JSON and Markdown summaries to `.eval-results/`.
</acceptance_criteria>
</task>

<task>
<name>Build Main CLI Runner and Wire package.json</name>
<read_first>
  - package.json
  - src/eval/scenarios/index.ts
  - src/eval/reporter.ts
  - src/eval/exporter.ts
  - src/db/postgres.ts
</read_first>
<action>
1. Create `src/eval/index.ts`:
   - Imports `initDb` from `../db/postgres.js` and initializes connections.
   - Iterates through `allScenarios`, running each scenario sequentially while capturing microsecond start/end times.
   - Flattens all `EvalCaseResult[]`.
   - Computes metrics via `computeMetrics`.
   - Displays terminal scorecard via `renderTerminalScorecard`.
   - Persists artifacts via `exportReports`.
   - Process exit code logic:
     - If `criticalFailures > 0` or `unauthorizedExecutions > 0` -> `process.exit(1)`
     - Else -> `process.exit(0)`
2. Update `package.json`:
   - Add script: `"eval": "tsx src/eval/index.ts"` under `"scripts"`.
3. Update `.gitignore`:
   - Ensure `.eval-results/eval-*.json` timestamped archives are ignored if desired, but keep `.eval-results/latest.json` trackable or ignore entire directory except gitkeep.
</action>
<acceptance_criteria>
- File `src/eval/index.ts` exists and can be run with `tsx src/eval/index.ts`.
- `package.json` contains `"eval": "tsx src/eval/index.ts"`.
- Running `npm run eval` executes all 11 scenarios, prints the terminal scorecard, writes reports to `.eval-results/`, and exits with code 0 or 1 based on test results.
</acceptance_criteria>
</task>

## 3. Engineering Learnings & Takeaways

1. **Evaluator Assertiveness:**
   Prior to Phase 8.1, mutations like MUT-07 (Double Approval) would have escaped because the old assertion checked `approvalSuccesses.length >= 1`. Tightening assertions in Phase 8.1 ensured MUT-07 was immediately killed.
2. **Topological Invariant Proof:**
   MUT-08 proved that without deterministic `ORDER BY id ASC`, parent/child foreign key relationships cause silent corruption during restoration. The evaluator reliably surfaces database foreign key failures.
3. **Hygiene as an Invariant:**
   MUT-12 proved that the post-stress inspection query accurately detects orphaned state even when tests themselves succeed.
